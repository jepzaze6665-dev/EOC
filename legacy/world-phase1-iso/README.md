# World Phase 1 — Isometric version (archived 2026-09-24)

The first World Engine used an isometric projection and a village generated
from code (tiles + props). It was replaced by the top-down 3/4 **image map**
engine so the game matches the painted maps in `docs/Map/`.

Kept for reference: iso math, tile/prop definitions, the procedural 100x100
Lumina Village, the isometric renderer with visible-tile culling, and its tests.
These files are not loaded by the game.
